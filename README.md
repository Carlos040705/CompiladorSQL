# CompiladorSQL

Proyecto de la materia Compiladores

Para ejecutar el proyecto es necesario tener un entorno virtual python.
Nota: hay un archivo con todas las dependencias necesarias.
Comandos en orden:

#Crear el entorno virtual (le llamamos env pero le puede poner como quiera)
python -m venv env

#encender el entorno virtual
./env/Scripts/activate

#instalar las dependencias
python -m pip install -r requirements.txt

#ejecutar el programa
python /Main/main.py

Nota: Las rutas se escriben diferente dependiendo el sistema operativo. El archivo main.py se tiene que ejecutar desde la carpeta raíz (a la altura de Main y env), esto se debe a la manera en que python busca las dependencias.
